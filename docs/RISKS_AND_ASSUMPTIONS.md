# RISKS_AND_ASSUMPTIONS — عازب | AZIB

## 1. الافتراضات (Assumptions)
1. Expo + React Native + TypeScript هو الأساس، بلا خروج عنه في هذه المرحلة.
2. العربية هي اللغة الافتراضية، RTL إلزامي.
3. Demo Mode يعمل بلا شبكة إلزامية.
4. لا مدفوعات حقيقية حتى إشعار صريح.
5. الأجهزة الضعيفة مستهدفة (Android متوسط/منخفض).
6. المستخدمون قد يفتحون التطبيق أول مرة دون فهم كامل لقيود Demo → يجب أن يكون الوسم واضحاً.
